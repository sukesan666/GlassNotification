# GlassNotification の使い方

## 通知を表示する

MSIX版をスタートメニューから起動するとWindows通知との連動を開始します。初回はWindows通知へのアクセスを許可してください。通常の未登録EXEから使う場合は、画面のWindows登録・連動の案内に従います。

設定ウィンドウを開くと設定モードになり、サンプルカードを固定表示したまま調整できます。通知音は「試聴」で確認できます。「動作モード」を選ぶか通知領域へ最小化すると、通常の通知受信とアニメーション表示に切り替わります。

通知カードをクリックすると元の通知の操作を実行します。元の通知が削除済み・操作できない種類の場合など、リンクや通知元を開けないことがあります。

通知カードは設定した表示時間が経過すると自動で閉じます。

## 基本設定

- 表示時間: 通知を表示する時間を変更します。
- 通知画像の大きさ: 画像の表示サイズを変更します。
- 通知画像の位置: 画像を左または右に表示します。
- アプリの拡大率: 設定画面の倍率を変更します。
- テーマ: システムに合わせる／ライト／ダークを選べます。

表示時間、通知画像の大きさ、アプリの拡大率、カードの幅・高さ、文字サイズ、余白はスライダーで調整します。設定変更は保存され、プレビューと以後の通知に反映されます。

## 見た目と配置

カードの幅・高さ、文字サイズ・フォント、カードと文字の色、角丸、表示するモニター、画面内の位置、端からの余白を変更できます。本文や画像を収めるため、カードの高さが指定値より大きくなる場合があります。

「文字の縁取り色」で、文字の色とは別にアプリ名・タイトル・本文の縁の色を選べます。「その他…」では任意の色を指定できます。「縁取りなし」で解除でき、初期状態では無効です。高コントラスト表示中は、読みやすさを優先して縁取りを表示しません。

背景は次から選べます。

| 設定 | 見え方 |
| --- | --- |
| Acrylic | 背後をぼかす、すりガラス風の背景 |
| Mica | 壁紙になじむ背景素材 |
| オフ | 不透明な背景 |

「すりガラスの強さ」の弱・標準・強はAcrylicの色と明るさの重なりを調整します。ぼかし半径を直接変更する設定ではありません。

Windowsの透明効果、省電力、ハイコントラスト、背景にあるウィンドウなどにより見え方が変わります。スライド中と停止後では使用する背景の描画方式が違うため、色やぼかしの見え方に差が出る場合があります。GPUでの表示やアニメーションを利用できない環境では代替処理を使います。

## 画像の選び方

通知の画像は、取得できたものを次の順番で表示します。

1. 本文画像
2. 送信者アイコン
3. アプリアイコン

画像は左右どちらかの拡大枠に表示します。通知元が画像を含めていない場合や、画像ファイルが既に削除されている場合などは取得できません。

## 通知元・通知音

通知元ごとにカード表示を調整できます。Windows標準の通知バナーと通知音の抑制は別々に設定できます。元に戻すボタン、連動の停止、アプリ終了時の復元処理があります。Windows標準通知の操作は、アプリ独自のポップアップや独自音には適用されません。

通知音は、なし・標準音・音声ファイルから選べます。「試聴」で音だけを確認できます。

## 通知領域・自動起動

通知領域のメニューから、設定画面の表示、一時停止・再開、終了を操作できます。設定画面ではWindowsへのサインイン時の自動起動と、通知領域に最小化して起動する設定を変更できます。

## 設定の保存先

- MSIX版: `%LOCALAPPDATA%\GlassNotification.OSLink\settings.json`
- 通常のEXE版: EXEと同じフォルダーの `settings.json`

配布ファイルには個人設定や実際の通知履歴を含めていません。

## 表示・受信に問題があるとき

1. 設定モードでカードが表示されるか確認し、受信を確認するときは動作モードに切り替えます。
2. 一時停止や通知元の非表示設定を確認します。
3. Windows側で元アプリの通知が有効か、通知アクセスを許可しているか確認します。
4. 背景の問題はオフ／Acrylicの切り替え、Windowsの透明効果と省電力設定を確認します。

問題を報告するときは、バージョン、Windowsのバージョン、再現手順、背景モード・色・強さ、スライド中か停止後かを添えてください。スクリーンショットに個人の通知内容が映る場合は隠してください。
