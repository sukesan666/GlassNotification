# 開発・配布手順

## 開発環境

- Windows 11 22H2以降（x64）
- .NET Framework 4.8
- Visual Studio 2022またはBuild Toolsの「C++によるデスクトップ開発」
- Windows SDK（Windowsメタデータ、MakeAppx、SignToolを含む）
- 初回の依存パッケージ取得用インターネット接続

アプリはC# / WPFとC++で構成されています。ネイティブビルドはVisual Studio Installerの `vswhere.exe` からC++ツールを検出します。Windows App SDKとC++/WinRTは公式NuGetから固定バージョンを取得し、SHA-256を確認します。

## ビルド

リポジトリのルートで実行します。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\outputs\GlassNotification\build.ps1 -Test All
```

この起動時の `-ExecutionPolicy Bypass` はそのPowerShellプロセスに指定するもので、PC全体の実行ポリシーを変更しません。

通常版EXEと連動版EXEを生成してから、ネイティブ・パッケージ・C#テストを実行し、成功後に署名付きMSIXを生成します。初回のクリーンなソース取得でも、パッケージテストが必要とするEXEを先に作る順序にしています。

出力先は `outputs/GlassNotification/` です。

| ファイル | 用途 |
| --- | --- |
| `GlassNotification.exe` | 通常版 |
| `GlassNotification.Linked.exe` | Windows通知と連動する版 |
| `GlassNotification.OSLink.msix` | 本体とランタイムを含む配布用パッケージ |
| `GlassNotification.OSLink.cer` | 署名証明書の公開部分 |

DLL・PRIなどの依存ファイルも生成されます。EXEだけを別のフォルダーへ移動して配布しないでください。MSIXで配布する場合は、それらを個別に渡す必要はありません。

`work/` はビルドキャッシュ・テスト作業・署名情報に使われ、Git管理から除外されています。依存DLLや生成EXEも除外し、配布するMSIXとCERは `dist/` に明示的に配置します。

## 署名の扱い

既存の署名証明書を使える環境ではそれを再利用します。利用可能な証明書がない場合は新しく作成します。プロファイルを利用できない環境では、暗号化した署名情報を `work/signing/` に保存する経路があります。

**署名の秘密鍵はこのリポジトリに含まれていません。** 新しいPCや別のビルド環境で署名すると、同じ名前でも異なる証明書になる場合があります。既存配布版の更新を作る場合は、配布に使った署名IDを安全な別管理から用意し、CERの拇印が一致することを確認してください。`.pfx`、`.p12`、`.key`、`.dpapi` や署名用フォルダーをGitへ追加しないでください。

現在の `dist/` の証明書拇印:

```text
0F192BA25A6F5B3B49613AC3DBFE2194CBBF40BA
```

## 配布版を更新する

1. `outputs/GlassNotification/identity/AppxManifest.xml` の `Identity Version` を現在の配布版より大きくします。同一ID・同一バージョンで内容を変えると更新できません。
2. `build.ps1 -Test All` を実行してテストとパッケージ生成を確認します。
3. 実機で通知の受信、画像、クリックと閉じるボタン、背景の各モード・強さ、スライド、自動起動を確認します。自動テストの成功だけでは見た目の一致までは保証しません。
4. 生成されたMSIXとCERを `dist/` にコピーします。
5. READMEとインストール手順のバージョン・証明書拇印を揃えます。
6. 署名が有効か、MSIXのバージョンが正しいか、個人設定が入っていないかを確認します。

```powershell
Copy-Item .\outputs\GlassNotification\GlassNotification.OSLink.msix .\dist\ -Force
Copy-Item .\outputs\GlassNotification\GlassNotification.OSLink.cer .\dist\ -Force
Get-AuthenticodeSignature .\dist\GlassNotification.OSLink.msix
Get-FileHash .\dist\GlassNotification.OSLink.msix -Algorithm SHA256
```

READMEからのダウンロードに加え、GitHub Releasesを使う場合はMSIX・CER・インストール手順をリリースの添付ファイルにします。

## 新しいGitHubリポジトリへの登録

このフォルダーは新しいローカルリポジトリです。旧リポジトリの履歴やリモートは引き継いでいません。GitHub側はまだ作成・公開していません。

後でGitHubに `GlassNotification` という空のリポジトリを作成し、そのURLを `origin` に登録します。READMEなどの自動作成はオフにすると、ローカルの初期コミットから登録できます。

```powershell
git remote add origin https://github.com/自分のユーザー名/GlassNotification.git
git push -u origin main
```

上のコマンドは公開作業を行う段階で実行してください。準備作業では実行していません。誰でもダウンロードできるようにするにはGitHub側の公開範囲をPublicにします。

## 公開前の確認

`git ls-files` でコミット対象を確認してください。含めるのはソース・必要な素材・第三者ライセンス・説明書・配布用MSIX/CERです。個人設定、通知データ、秘密鍵、作業ログは含めません。

本アプリ本体のライセンスはまだ選択していません。第三者コンポーネントのライセンスは `outputs/GlassNotification/licenses/` に収録しています。
